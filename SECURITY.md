# Security

XyloNet runs on Arc mainnet with real funds. If you find a vulnerability in the contracts, the app or the extension, please tell us privately first.

- Email: forgelabs@xylonet.xyz
- Please include a description, the affected component and steps to reproduce. Do not test against live user funds.
- We acknowledge reports within 48 hours and keep you informed while we fix the issue.

Scope: `payx/contracts` (PayXTipping v2 on Arc, address in `docs/ADDRESS_BOOK.md`), the `web/` application and its API routes, and the PayX Chrome extension. Third-party components (LI.FI, Circle CCTP and Gateway, wallets) should be reported to their own programmes.

Please do not open public issues for security reports.
