# Contributing

This repository is a read-only mirror of XyloNet's private working repository, published automatically on every release. Pull requests here cannot be merged directly, but they are read, and changes we take are credited in the commit that lands them.

- Bugs and ideas: open an issue with what you saw, where, and how to reproduce it.
- Security problems: do not open an issue; see [SECURITY.md](SECURITY.md).
- Questions: [discord.gg/mcDkHNrFyA](https://discord.gg/mcDkHNrFyA) or [@Xylonet_](https://x.com/Xylonet_) on X.

Code style follows the repository as it stands: TypeScript strict, ESLint with the React Compiler rules, design tokens only (no colour literals; `npm run build` enforces this), sentence case in copy.
